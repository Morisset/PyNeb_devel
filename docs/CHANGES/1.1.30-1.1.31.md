# Changes from 1.1.30 to 1.1.31

## New features

* **`Atom.plotGrotrian2`**: a new Grotrian diagram for collisional atoms, complementing
  `plotGrotrian`. Levels are laid out by spectroscopic term (with term symbols), and the
  transitions are drawn color-coded by log A(i,j) — or by line emissivity when `tem` and `den`
  are given — with a colorbar, a selectable colormap, and thresholds to only show transitions
  above a given transition probability (`A_lim`) or emissivity (`log_emis_lim`).
* **Runtime CHIANTI / Stout paths**: the database directories can now be set at runtime with
  `pn.config.set_chianti_path(path)` and `pn.config.set_stout_path(path)`, as an alternative to the
  `XUVTOP` / `STOUT_DIR` environment variables (which remain the import-time default).
  Passing `None` unsets them. Matching getters: `get_chianti_path()` / `get_stout_path()`.
  Side effect (documented): the setters also update the corresponding environment variable for the
  process, since the low-level CHIANTI readers use it. The CHIANTI version is re-read from
  `{path}/VERSION` and the version-specific tools module is re-selected, so a session started
  without `XUVTOP` can gain CHIANTI support at runtime.
* **New atomic data file** `o_iii_atom_TZ17_202.dat`: 202-level O III transition probabilities
  from Tayal & Zatsarinny (2017).
* `RecAtom.getEmissivity` now warns when the requested wavelength does not correspond to any
  known transition, instead of failing silently.

## Other changes

* NumPy 2.0 compatibility: `np.NAN`/`np.NaN` replaced by `np.nan` throughout.
* CI now tests on Python 3.8 and 3.12 (previously 3.8 only).
* All documentation notebooks rerun for this release.
* Packaging: the atomic data directories (`atomic_data`, `atomic_data_fits`,
  `plot/level_diagrams` and their subdirectories) are now declared as packages with their own
  `package-data` in `pyproject.toml`, removing the "Package would be ignored" warnings of
  recent setuptools at build time. The wheel contents are unchanged.

## Library bugs fixed

* `Observation.setAllErrors` read a nonexistent `line.obs_err` attribute, so it always crashed
  (`pynebcore.py`).
* `readData(fileFormat='lines_in_cols2')` used `np.string_`, removed in NumPy 2.0 — replaced with a
  dtype-kind check.
* `addMonteCarloObs` truncated `names` to the first object for multi-object observations (and used
  the deprecated `np.core.defchararray`).
* `save()` with positional args evaluated names in the wrong scope and always raised `NameError`;
  both `save()` and `restore()` also leaked file handles (`saverestore.py`).
* `EmisGrid.plotLineRatio` used `ContourSet.collections`, removed in matplotlib 3.10
  (`emisGrid.py`).
* `_AtomDataAscii` crashed when a data file has more levels than NIST provides
  (e.g. `o_iii_atom_TZ17_202.dat`, hit by `DataPlot('O', 3)`) — added the same NLevels clamp the
  Stout reader already had (`pynebcore.py`).
* `_CollDataStout` computed `NLevels` from the maximum *lower* level instead of the maximum *upper*
  level, losing the top level of the collision data (`pynebcore.py`).
* `DataPlot.plotA` set the x-ticks inside the per-dataset `try` block (matplotlib warning when a
  dataset failed) and indexed past its 5-entry marker list, so datasets beyond the fifth were
  silently never plotted — markers now cycle like the colors.
* Renamed the misplaced diagnostic script `pyneb/utils/test_config.py` → `check_config.py`
  (its `test_*` name got it collected by pytest discovery, and it had a latent `NameError`);
  verified it still runs standalone.

## Warnings cleaned up

* `np.genfromtxt` deprecation — added `encoding=None` to both `readData` call sites in
  `pynebcore.py` (`lines_in_cols2` and `lines_in_rows_err_cols`).
* `two_photon` invalid-power warning — wrapped the fit formula in
  `with np.errstate(invalid='ignore'):` in `continuum.py`; the NaNs for y > 1 are zeroed by the
  mask right below.
* Divide-by-zero from degenerate levels — wrapped the three 1/ΔE-style loops
  (`_AtomDataAscii.initWaves`, the B-coefficient loop in `Atom`, and `initWaves` in
  `pn_chianti.py`) in `np.errstate(divide='ignore', invalid='ignore')`.
* `FigureCanvasAgg is non-interactive` — added a `filterwarnings` ignore to
  `[tool.pytest.ini_options]` in `pyproject.toml`, since `plt.show()` is deliberately a no-op on
  the test backend.
* Latent `SyntaxWarning`s — invalid escape sequences (`'\.'`, `'\*'`, `'$\Omega$'`, `'\+'`) in
  `pn_chianti.py`, `plotAtomicData.py`, and `apap.py` converted to raw strings. These warned on
  every fresh install, and Python is moving toward making them errors.

## Full test suite

16 test files, 253 tests, all passing (`pytest tests --doctest-modules`, mirrored by CI on
Python 3.8 and 3.12; the suite also passes without `XUVTOP` / `STOUT_DIR` set, as on CI).

Shared fixtures live in `conftest.py`: session-scoped atoms (`O3`, `N2`, `S2`, `O2`),
recombination atoms (`H1`, `He2`), a small 10×8 `O3_grid` emissivity grid, the `smc24_path`
sample file, plus the forced matplotlib Agg backend. See `tests/README.md` for the full
documentation of the suite.

### Core physics classes

* `test_atom.py` — 60 tests. The collisional `Atom` class. Constructor variants and attributes
  (`elem`/`spec`/`Z`/`NLevels`, energy and wavelength arrays); `getA` (matrix structure, known
  [OIII] 5007/4959 values, lookup by wavelength); `getEnergy` ordering; `getOmega`/`getCollRates`
  shapes and positivity; `getPopulations` normalization; `getEmissivity` (absolute values for
  5007/4959/4363, line ratios, scalar/array/product shapes, temperature dependence);
  `getCritDensity`; `getTemDen` roundtrips (N II temperature, S II density) with `to_eval`, wave,
  and level syntaxes; `getTransition`; `printIonic` smoke tests.
* `test_recatom.py` — 18 tests. The `RecAtom` class (H I, He II): constructor attributes,
  `getWave` for Hα/Hβ/He II 4686, emissivity values including the Balmer decrement (~2.85) and
  Hγ/Hβ ratio, temperature dependence, density insensitivity, and the module-level
  `getRecEmissivity` helper's agreement with `RecAtom`.
* `test_continuum.py` — 11 tests. The `Continuum` class: continuum shape/positivity/magnitude,
  the Balmer-jump discontinuity sign, normalized output shapes for temperature arrays, `BJ_HI`
  decreasing with Te, a `T_BJ` roundtrip recovering 10⁴ K to 0.1%, the closed-form `T_BJ_Liu`,
  two-photon continuum (zero below Lyα, suppressed at high density), Gaunt factors of order
  unity, free-free increasing with helium, and NaN returns for invalid `make_cont_Ercolano`
  inputs.

### Observations and analysis

* `test_observation.py` — 39 tests. `EmissionLine` (constructors by elem/spec/wave and by label,
  blends, invalid labels, relative-vs-absolute errors, `correctIntens`, `addObs`, `printLine`)
  and `Observation`: reading all four ASCII formats (`lines_in_cols`, `lines_in_cols2`,
  `lines_in_rows` via `smc24.dat`, `lines_in_rows_err_cols`), line access (`getLine`,
  `getIntens`, `getError`, sorting, unique atoms), editing (`addLine`, `removeLine`, `fillObs`,
  `addObs`, `addSum`), extinction (`def_EBV` + `correctData` restoring the Balmer ratio to 2.85),
  Monte Carlo replication for one and two objects, and `setAllErrors`.
* `test_diagnostics.py` — 16 tests. The `Diagnostics` class: the diagnostics catalog
  (≥100 entries, known labels), `addDiag`/`addAll`/`delDiag`/`getDiagFromLabel`,
  `getUniqueAtoms`, and `getCrossTemDen` (an [OIII]+[SII] roundtrip and an [NII]+[SII]
  physical-range check).
* `test_icf.py` — 12 tests. The `ICF` class: catalog queries (`getAvailableICFs`, filtered by
  type), metadata (`getExpression`, `getType`, `getComment`, `getReference`, `getURL`), and
  `getElemAbundance` with hand-checkable inputs (direct O sum = 3×10⁻⁵, ICF factor exactly 3 for
  TPP77_14, ICF ≥ 1 sanity), array inputs, NaN for absent ions, and `addICF`/`delICF`.
* `test_emisgrid.py` — 13 tests. The `EmisGrid` class: grid shapes and Te/Ne ranges, `getGrid`
  by wavelength/levels/`to_eval`, physical invariants (5007/4959 constant ≈ 2.98, 4363/5007
  strictly increasing with Te), save/restore roundtrip and recompute-on-mismatch,
  `getEmisGridDict` compute-then-cache behavior, and smoke tests for
  `plotImage`/`plotContours`/`plotLineRatio`.

### Golden-value regression tests

* `test_golden.py` — 10 tests. Compares 54 numerical quantities against reference values stored
  in `tests/golden_values.json`, computed once and committed: collisional emissivities (O III,
  N II, S II, O II), O III level populations, transition probabilities, critical densities,
  `getTemDen` solutions, recombination emissivities, extinction corrections (CCM89, F99), the
  nebular continuum, ICF abundances, and `getCrossTemDen`. A failure means the numerical output
  of the library changed; if intended, regenerate with `python tests/test_golden.py --update`.

### Extinction, data management, utilities

* `test_extinction.py` — 21 tests. The `RedCorr` class: defaults (R_V = 3.1), E(B-V) ↔ cHβ
  roundtrip, `getCorr` (unity for no correction or zero reddening, wavelength dependence, array
  input), `getCorrHb`, `setCorr` from observed ratios, and the catalog of ≥12 laws (CCM89, F99,
  Cal00, …).
* `test_atomic_manager.py` — 7 tests. The `pn.atomicData` singleton: `getDataFile`,
  `getAllAvailableFiles` (with the `*` current-file marker), `getAllAtoms` (collisional and
  recombination), predefined dictionaries (PYNEB_23_01), and a `setDataFile` switch-and-restore
  roundtrip verified on a freshly built atom.
* `test_chianti.py` — 1 test. Loads O III atom+collision data in CHIANTI format from the bundled
  `tests/CHIANTI/` tree (version 10.0.1) via `pn.config.set_chianti_path()` and builds a
  19-level atom; passes with or without a real CHIANTI installation.
* `test_stout.py` — 2 tests. Loads O III atom+collision data in Stout format from the bundled
  `tests/STOUT/` tree (truncated to 5 levels from Cloudy c23.01) via
  `pn.config.set_stout_path()`: Stout ion discovery, `setDataFile('*.stout')`, tabulated Ω/A
  round-trips, the NLevels regression, and clean revert of `set_*_path(None)`.
* `test_physics.py` — 10 tests. `airtovac`/`vactoair` (IDL reference value, roundtrip,
  vacuum > air, no-op outside the conversion window), `gsFromAtom` ground states, `CST`
  constants (Hβ wavelength, Rydberg, Boltzmann), and `getHbEmissivity` against both the Aller
  fit and H I recombination data.
* `test_helpers.py` — 14 tests. `getLineLabel` / `parseLineLabel` (plain lines, blends, micron
  wavelengths, `H1r` labels), `isValid`, `getAtomDict`, and `save`/`restore` (kwargs and
  positional paths, error on unknown names).
* `test_utils.py` — 14 tests. `int_to_roman`/`roman_to_int` (including a full 1–3999 roundtrip),
  `parseAtom`, and `ROOT_DIR`.
* `test_plotting.py` — 5 tests. Agg-backend smoke tests that assert content was actually drawn:
  `Atom.plotEmiss`, `Atom.plotGrotrian`, `RedCorr.plot`, `DataPlot.plotA` (loads every O III
  dataset), and `Diagnostics.plot` over the `O3_grid` with a synthetic corrected observation.
